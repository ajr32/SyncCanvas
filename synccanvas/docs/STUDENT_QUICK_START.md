# SyncCanvas — Student quick start

SyncCanvas helps you remember work that may not be written clearly in Canvas. You do **not** need to write a long description.

## During the school day
1. Open **Add Information** (`/add`).
2. Choose the class.
3. Choose what kind of work it is: finish classwork, homework, study, prepare for a quiz, or ask a teacher.
4. Type a few words, like “finish problems 4–8.” Press **Save**.
5. If there is nothing to add, you can use the detailed class check-in from the Add Information page. Do not invent homework.

## At school check-out
1. Open **School Check-Out** (`/review`) with the person helping you, if available.
2. Go through **every class**, even if nothing was entered.
3. Choose **Reviewed**, **Reviewed — nothing needed**, or **Reviewed — needs follow-up**, then save that class review.
4. Write down unclear instructions as a question. Leave **Resolved** unchecked until someone has answered it.
5. Check the accordion pocket at the front of the binder and any loose papers in the backpack. Save the paper check.

## At home
Open **My Afternoon** (`/afternoon`). Work with your parent on the items for today. Future work appears separately under **Planned for later**. Canvas still controls official assignment deadlines.

**Remember:** A short note is better than forgetting. Ask for help when you don't know what to enter.
