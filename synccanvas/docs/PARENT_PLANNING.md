# Parent task planning and completion

## Add and plan
In `/parent`, add a task under the correct class with a short description. A **planned work date** is when the family intends to work; it is **not** a change to the teacher's Canvas due date. Future work appears in **Planned for later** on `/afternoon`.

## Completion distinctions
Student completion, Canvas submission, and parent confirmation are different. The parent may confirm completed work or return it for more work. Do not assume a Canvas submission proves comprehension.

## Linking local and Canvas work
A local note can link to a same-class Canvas assignment. This is a relationship, not an overwrite. The afternoon display may group them, but the local note and Canvas assignment retain independent status. Unlinking must preserve both records; different-class links should be rejected.

## Check it
Create two disposable tasks, one for today and one for a future date. Verify future task is listed once under Planned for later. Change the planned date without changing any official Canvas due date. Link/unlink a same-class task, and try a cross-class link to verify rejection. Confirm and return a task and inspect its state.
