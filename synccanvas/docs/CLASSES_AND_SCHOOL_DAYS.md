# Classes, bell schedule, and school-day settings

From `/settings`, navigate to **Manage Classes and Canvas course links**, **Bell Schedule**, **School Days**, or **Lunch Buddies**.

## Classes
The class management UI includes manual class creation, renaming, ordering, enabling/disabling, archiving, deletion, and Canvas-course linking. Review effects before deleting a class; try destructive actions only on disposable data.

## Bell schedule
The parent schedule UI supports adding, updating, assigning, and deleting class periods. Verify start/end times and selected days before saving. School-day exceptions are configured separately.

## Verification
Confirm active classes appear in the same order on student and school check-out screens. Verify archived/disabled classes are not treated as active check-out requirements. Check schedule times against a real bell schedule. Do not assume every school-day exception automatically changes every other feature without testing.
