# Canvas authority and uncertainty

Canvas is the official assignment source **when information is available**. Local notes supplement it with verbal instructions, unfinished classwork, practice, materials, and questions.

- Do not infer “no homework” from an empty Canvas page.
- Do not infer understanding from Canvas “submitted”.
- Do not silently replace official due dates with parent work plans.
- Keep a local note if Canvas is incomplete or unavailable.
- Prefer linking related local/Canvas records over duplication or overwriting.
- Check the actual Canvas page before resolving conflicting due dates or statuses.

## When sync seems wrong
Verify the class-to-course mapping in `/parent/classes`; check the teacher's Canvas page; inspect sync status; preserve local notes. Do not put Canvas tokens or student information in GitHub reports.

The application has `GET /api/sync/status` and sync-run endpoints. Their existence does not prove that live school credentials, API edge cases, or external calendars were verified. Keep the prototype local.
