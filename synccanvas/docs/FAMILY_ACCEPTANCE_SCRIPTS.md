# Family acceptance scripts (not yet executed)

For each scenario record **date, tester role, device, pass/fail, notes, GitHub issue**.

1. **Verbal homework absent from Canvas:** Add a short local note; confirm it appears without fabricating an official assignment.
2. **Unfinished classwork:** Student selects “Something I still need to do”; parent sees it at home.
3. **Unknown worksheet:** Save a needs-follow-up class review and an unresolved question; reload and confirm it remains unresolved.
4. **Physical handoff:** Save binder-pocket and backpack checks; confirm persistence without claiming staff identity.
5. **Postpone work:** Move local planned work date; verify official Canvas due date is unchanged.
6. **Related Canvas item:** Link and unlink same-class records; verify both remain and completion stays separate.
7. **Daily math:** Complete today's recurring practice; verify it doesn't complete tomorrow's.
8. **Parent review:** Return student-completed work; verify it is not parent-confirmed.
9. **No work today:** Review an empty class and explicitly record “nothing needed”; don't infer it automatically from Canvas.

A green automated suite is not a substitute for this acceptance session.
