# SyncCanvas — Parent afternoon and check-out guide

**Scope:** Local family prototype. It has no login-based separation between parent and student screens and does not authenticate school staff. Do not expose it to the internet or treat saved review records as verified staff signatures.

## Afternoon review
1. Open **My Afternoon** (`/afternoon`) for the work planned now. Check **Planned for later** before assuming future work is missing.
2. Open **Parent Review** (`/parent`) to review student notes, plan tasks, and add missing homework, study, or follow-up items.
3. Use the parent task form to choose a class, kind of work, description, and optional **planned work date**.
4. Change the planned date to move work to another afternoon. **This does not change the official Canvas due date.**
5. When a local task corresponds to a Canvas assignment, link the two rather than copying or overwriting the Canvas assignment. A link groups related work; it does not make a parent note the authoritative Canvas record.
6. Use parent confirmation or return-for-more-work as appropriate. Canvas submission/completion is not proof that the student understands the material.
7. Use **Settings** (`/settings`) for recurring expectations such as regular math practice; the exact frequency and duration are family decisions.

## School check-out and paper flow
The **School Check-Out** page (`/review`) displays all active classes, student check-in status, locally saved review outcomes, read-only Canvas context, and local notes. Review each class even when there is no recorded work. If information is missing, save a question and mark the class **needs follow-up**. The physical-paper check is limited to the binder's front accordion pocket and loose backpack papers; it is not an inventory of every worksheet.

## Exceptions
- **No class shown:** Configure active classes in Settings / parent class management before student entry.
- **No work recorded:** Ask about the class; do not automatically interpret an empty Canvas list as “no homework.”
- **Unclear instructions:** Record a question, leave it unresolved, and follow up with the teacher or aide.
- **School aide unavailable:** Parent and student can still use the family workflow. Do not represent a parent-entered review as an authenticated school review.
- **Task planned for a later date:** Look in **Planned for later** rather than treating it as missing.
- **Official due date disagrees with home plan:** Keep Canvas as the official due-date source; revise only the planned work date.

## Limits
The app currently runs as a local prototype. Account authorization, staff identity, school Chromebook access, live family acceptance, and production deployment are separate unfinished work items.
