# SyncCanvas — Student User Guide

*Working guide · October 2026 · Update as the app changes*

## What SyncCanvas does

SyncCanvas helps you see your classes, write down what you need to do, and track your progress. It can also show assignments brought in from Canvas when your family has set up that connection. **SyncCanvas does not submit your assignments to Canvas.**

## 1. Start your day

1. Open SyncCanvas and go to the student home page.
2. Look at your classes and any school-day notice, such as **No school today** or **Shortened / special school day**.
3. Check the work shown for each class. Canvas assignments and tasks added in SyncCanvas may appear together, but they are not the same record.

## 2. Check each class

For each class, decide what you need to do:

- **Add task & check in:** Choose a task type and write what you need to do. For example, choose **Study** and write “Review vocabulary for 15 minutes.”
- **Nothing Tonight:** Use this only after checking the class and deciding there is no work to record for tonight.
- **Checked — still deciding:** Use this if you checked the class but have not decided what to enter yet.

You can return and add a task later. **Nothing Tonight** is a check-in, not a completed homework assignment.

## 3. Follow your homework plan

Open the homework or afternoon plan and read each task card. The task type and class help you understand what the task is for. If your parent has added a practice or study expectation, it may appear here as well.

## 4. Update your progress

For a task in the homework plan:

1. Find the **Progress** menu on its card.
2. Select **Not started**, **In progress**, or **Done**.
3. Choose **Save progress**.
4. Check that the new state is shown when you return to the plan.

**Not started** means you have not begun. **In progress** means you are working on it. **Done** means you finished it. If you marked something Done by mistake, choose **In progress** or **Not started** and save again. A parent may still need to review work you have marked Done.

## 5. Understand dates

A **work date** is when you plan to work on something. A **due date** is when the assignment is due. These can be different. Changing your plan does not change an assignment's Canvas due date.

## 6. Canvas assignments

If a task came from Canvas, open the Canvas link when you need to read the teacher's full instructions or submit work. Do not assume marking a SyncCanvas task Done submits anything to Canvas. If something looks wrong or missing, ask your parent to check the connection.

## 7. If something goes wrong

- **I entered the wrong task:** Ask your parent for help editing it if you cannot find the edit control.
- **I marked something Done too early:** Change Progress back to In progress or Not started and save.
- **I cannot see a class:** Ask your parent to check which classes are active.
- **I see “No school today”:** This is a schedule notice. Check your assignments anyway; existing tasks do not automatically disappear.
- **Canvas is not updating:** Ask your parent to check for updates and verify the Canvas connection.

## A quick end-of-day check

Check every class, add what needs doing, update progress honestly, and ask a parent about anything uncertain. You do not have to finish every task to record useful progress.

## Dates and daylight saving time

The planner uses your family's local calendar day. You don't have to change anything when the clocks move forward or backward. Canvas assignments are shown with their due **date**, not a due-time setting you need to manage. If a date looks wrong, ask your parent to check the computer's timezone and refresh Canvas.


## Homework features and limits — issue group #387

### Types of work (#58)

When recording work, choose the type that best describes it: **Homework**, **Study**, **Finish Classwork**, **Prepare for Quiz**, or **Ask Teacher**, where offered. Give the task a specific description. **Nothing Tonight** is a class check-in, not a task to mark Done. If a type is not shown on your installed screen, ask a parent rather than guessing.

**Try it:** Add a Study task, return to your plan, and make sure the description and class are right. Check another class as Nothing Tonight and make sure it does not create a completed task.

### Starting, finishing, and reopening work (#59–60)

For a local task, choose **Not started**, **In progress**, or **Done** and save. Reopen a task by changing Done to one of the unfinished states and saving again. You can then mark it Done when it really is finished. Your parent may need to review it again.

**Try it:** Move a test task through all three states; reload the plan to confirm each state sticks. Reopen a completed task, then complete it again. The app tracks completion time internally, but you do not need to manage a timestamp.

### Work dates versus due dates (#61–62)

A **planned work date** tells you when to work on something. A **due date** tells you when it must be finished. If an assignment is due at school tomorrow, you may choose to work on it at home tonight. Canvas is the source for imported due dates. The reviewed prototype does **not** promise a separate **due-at-school** toggle, due-time editor, or priority control.

**Try it:** Find an assignment with a Canvas due date and compare it with the day you plan to work. Changing the plan must not change the due date in Canvas.

### Notes, links, and smaller steps (#63)

Write enough detail in the task description to remember what to do. Use the Canvas assignment link to read the teacher's original instructions when available. Separate editable notes, attached links, and checkable subtasks are **not confirmed as complete features** in this prototype; do not depend on them until they have been implemented and tested.

### Today and tonight (#65)

Use the student home page to check classes, then use the afternoon or homework plan to see what needs attention. A task you have not finished should not disappear merely because you checked in. Ask your parent to investigate if something is missing.

**Try it:** Add an unfinished task, visit the plan, reload, and make sure it is still there. Test the empty-plan view without creating a fake completed assignment.

### Repeating work and special school days (#69–72)

A parent may add a repeated Study expectation. It can appear on days matching the rule. School closures and shortened-day notices tell you about the schedule; they do not erase homework. When clocks change for daylight saving time, keep using the dates shown in the planner; tell a parent if a Canvas due date looks incorrect.

**Try it:** Ask a parent to create a weekday Study expectation and check an applicable day. On a saved no-school date, confirm the notice appears but existing tasks remain available.

### Features not part of the current family workflow (#64, #66–69)

Undo/edit history, seven-day and month views, class/status filters, and the broader repeating-routines feature are tracked as **deferred 2.0 work** in GitHub group #387. Do not expect those screens just because they are listed in the roadmap. The limited parent-configured recurring Study expectation described above is already present in the reviewed prototype.


## School Check-Out — end of the day (issues #82–#86, #88)

**This is a quick second look at each class, not a second homework list.** Before leaving school, open **School Check-Out**. For each class:

1. Ask yourself: **Did I review this class and write down everything I need to do at home?**
2. Look at the work already recorded and any Canvas assignments shown. If you forgot something, use **Add it to your class notes** to record it in the usual place.
3. Think about what you need to take home: binder, papers, books, Chromebook, or other materials. If something is missing or unclear, write a short optional note, such as “Need math workbook.”
4. Use **✓ I reviewed this class**, near the top of its card. If you need to look again, use **Review again**.

The page shows how many classes you have reviewed. When all classes are reviewed, **check your bag** before heading home. Reviewing a class does **not** mean its homework is finished, and it does not submit anything to Canvas.

The six original issue ideas (#82, #83, #84, #85, #86, and #88) are handled by this **simpler family workflow**. You do not need teacher signatures, a separate reviewer form, an extra packing inventory, or formal exception paperwork. If you are unsure about something, record a note and talk about it at home.

## Saving your work

After you press a Save, Add, or other submit button, you may see **Working…** and **Saving or loading… Please wait.** Wait for the next page rather than pressing the button repeatedly. If an error page appears, ask a parent to help check whether the task was saved before trying again. The message means the app is working; it does not guarantee a save succeeded.

When you write a homework task, enter it once. If you return to the page and see the task already listed, do not add it again. Your family's Canvas assignments remain in Canvas; SyncCanvas is for planning and tracking, not submitting schoolwork.


## Adding information without JavaScript (issue #24)

**Add Information** works as a regular form, including on a school Chromebook with JavaScript turned off or unavailable. Select the correct class, choose the kind of work, write a few words, and select **Save**. The work goes into that class and appears in the usual planner and parent review. You do not need to change any browser settings. If the class is missing, ask a parent to check the class setup. If a form says information is missing or invalid, return to it and correct the field.



## Classroom check-out (issues #74–#78)

1. Open **School Check-Out** and check each class. Add Homework, Study, or Finish Classwork from **My Classes** when needed; enter what to do and an optional due date (no due time).
2. On School Check-Out, mark the class **Checked**, **Nothing to do**, or **Needs clarification** under **Change checkout status**. A class you have not reviewed yet is **Unchecked**.
3. Under **What must go home?**, add a book, paper, device, or other item, then tap **Packed** once it is in your bag.
4. Made a mistake? Change the class status again. **Earlier corrections** shows what changed and when.

If you are unsure about homework, choose **Needs clarification** and add a question instead of guessing. If the packing list is empty, add only what you need; there is no requirement to add an item every day.


## Navigation and screen sizes

Use the navigation links at the top to switch between My Afternoon, Add Information, and School Check-Out. On a phone, the links wrap into touch-friendly rows. On a tablet or Chromebook, the same pages expand to use the available width.

You can press Tab to move between links and fields; the focused control has a visible outline. A “Skip to main content” link appears when you first press Tab. Form fields have labels. If a page cannot be found, use the return-home link.

**Quick check:** Open School Check-Out on a phone-sized screen and a Chromebook-sized screen; confirm no horizontal scrolling is needed for the main controls. Use Tab to reach the checkout buttons. Visit a missing URL such as `/missing-page` and confirm the return link works.
